# 隐私合规草稿

以下为待确认草稿，需在微信公众平台后台按实际功能如实填写后提交。**后台勾选的内容必须与代码行为完全一致**，填写与实际不符会构成虚假陈述。

## 当前版本的实际行为

核对 `minigame/` 全部源码，本版本：

- 不调用任何获取用户信息的接口（`wx.getUserInfo`、`wx.getUserProfile`、`wx.getLocation`、相册、通讯录、蓝牙、麦克风等均未使用）。
- 不向任何服务器发送数据，没有网络请求，没有第三方 SDK，没有统计埋点。
- 不使用广告组件，不涉及支付、虚拟货币或内购。
- 没有登录、没有账号体系，没有客服会话以外的用户输入。
- 唯一的数据写入是 `wx.setStorageSync`（合合2048 的棋盘、得分、最高纪录、撤回次数、每日奖励日期、震动开关），仅保存在用户本机。
- 唯一占用的设备能力是振动（`wx.vibrateShort`，可在游戏内关闭）。

结论：**本版本不处理任何个人信息**。后台的《用户隐私保护指引》应据此勾选，不要勾选实际没有的能力；清理缓存会清空本机存档，这一点已在游戏内「关于」页面明示。

## 隐私保护指引草稿（后台填写用）

> 合合2048 是一款单机数字合并小游戏。游戏仅在你的设备本地保存棋盘、得分、最高纪录、撤回次数、每日奖励领取日期与振动开关，用于恢复未完成的对局。本游戏不收集、不使用、不向任何第三方提供你的个人信息，也不申请任何系统权限。清除小游戏缓存会同时清除上述本地数据。

如后续接入排行榜、广告、客服会话或任何需要联网的能力，必须先更新本文件并在后台重新提交隐私保护指引，否则「处理目的」与实际行为不符。
